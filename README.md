# LIFE DASHBOARD

A simple personal productivity dashboard built with HTML, CSS, and JavaScript.

## Features

- Dynamic greeting based on time
- Current time and date
- Custom user name
- To-do list
- Add, edit, complete, and delete tasks
- Task notes
- Prevent duplicate tasks
- Sort tasks
- Focus timer with adjustable duration
- Quick Links
- Light and Dark Mode
- Local Storage support

## Technologies Used

- HTML
- CSS
- JavaScript
- Kiro

## How to Use?

Open `index.html` in a web browser.

The application uses Local Storage to save user preferences, tasks, timer duration, and quick links.
